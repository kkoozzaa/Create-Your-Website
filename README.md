# WebDev Basics 🌐

Eine einfache Einführung in die Webentwicklung mit HTML, CSS und JavaScript.

## 📚 Über das Projekt

Dieses Projekt hilft Anfängern, die Grundlagen der Webentwicklung zu verstehen.

Du lernst Schritt für Schritt:
- **HTML:** Wie man eine Webseite aufbaut.
- **CSS:** Wie man eine Webseite gestaltet.
- **JavaScript:** Wie man eine Webseite interaktiv macht.

## 🚀 Funktionen

- Einfache Erklärungen für Anfänger
- Beispiele für wichtige HTML-, CSS- und JavaScript-Befehle
- Schritt-für-Schritt-Anleitung
- Beispiele aus dem Quellcode dieser Webseite

## 💻 Verwendung

1. Lade das Repository herunter.
2. Öffne die Datei `index.html` in deinem Browser.
3. Klicke auf „Los geht's!“ und beginne zu lernen.

Du brauchst keine zusätzlichen Programme oder Installationen.

## 🛠️ Technologien

- HTML5
- CSS3
- JavaScript

## 🎯 Ziel

Das Ziel dieses Projekts ist es, Schülern einen einfachen Einstieg in die Webentwicklung zu ermöglichen.

Viel Spass beim Programmieren!
